# Sanity CMS — przygotowanie dla Smerfików

Demo działa bez CMS i może być od razu wrzucone na Netlify.
Ten katalog to starter do docelowego panelu Sanity.

Docelowe typy treści:
- Placówki — adres, status, opis, telefony, godziny, zdjęcia, mapa.
- Aktualności — tytuł, data, treść, zdjęcie, przypisanie do jednej lub wszystkich placówek.
- Ustawienia strony — główne teksty, dane kontaktowe, komunikat w pasku.

Po akceptacji projektu warto stworzyć osobne Sanity Studio i podłączyć frontend do Sanity Content Lake. Do formularzy rodziców nie używamy Sanity — formularz może pozostać w Netlify Forms lub zostać podłączony do wybranego CRM.
